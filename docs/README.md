# VT Studio 功能清单

## 1. 项目定位

VT Studio 是一个本地桌面端 AI 短剧/视频生产工具。

核心流程是：

```txt
小说/原文 -> 剧本 -> 资产 -> 分镜 -> 图片 -> 视频候选 -> 导出
```
