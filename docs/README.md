# VT Studio 文档入口

项目硬规则以根目录 `AGENTS.md` 为准。本目录只保留当前有效文档。

| 任务 | 阅读文档 |
| --- | --- |
| 确认已有功能 | `项目功能清单.md` |
| 运行命令、依赖和技术栈 | `技术栈.md` |
| 修改代码、数据和文档 | `开发规则.md` |
| 修改生产流程 | `通用视频生产流程设计.md` |
| 修改供应商、模型能力和参数联动 | `模型能力审计与设计.md` |
| 查看未完成事项 | `后续目标与待办.md` |

维护规则：已有功能写入功能清单，未完成事项写入待办，流程和模型规则写入对应设计文档；不新增历史方案、参考项目长文或复杂文档目录。
