## 0. 快速理解

```txt
一句话：给开发和排错用的开关放到设置里，比如 DevTools、AI DevTools、本地存储查看。
为什么现在做：后续功能复杂，开发期需要排查工具，但不能让普通用户误操作。
做完后有什么用：开发环境能快速打开调试工具，查看和清理本地存储。
这一步不碰什么：不做业务设置，不给生产环境默认暴露危险工具。
```

## 2.1 本轮复核结论

```txt
复核时间：2026-07-02

当前 VT Studio 代码现实：
  1. `SettingsHome.vue` 已有开发者折叠区，但没有独立开发者配置组件。
  2. `window.vtStudio.settings` 里还没有 `dev` 能力。
  3. `app:get-info` 已返回 `isDev`，可以作为入口显示和按钮可用性的判断依据。
  4. `switchAiDevTool` 已在 `app_settings` 默认数据和模型常量中存在，但当前没有设置页读写 service。
  5. 当前代码未找到 `@ai-sdk/devtools` middleware 接线；如果保留 AI DevTools 开关，实现时必须让开关对后续文本模型调用真实生效，或在执行后记录中明确降级原因。
  6. renderer 本地状态已经包含登录、语言、外观等关键 key，不能照搬参考项目的无保护清空逻辑。

专业结论：
  1. 交互边界需要比 Toonflow 更克制。
  2. 不新增确认点，仍然保留本文第 9 节 3 个确认点。
  3. 未确认前不写代码。
```

## 4. 要做什么功能

### 1. 打开 DevTools

怎么做：
- 输入：无。
- 输出：DevTools 打开。
- 写什么数据：不写。
- 状态怎么变：无。
- 异常怎么处理：非 Electron 或生产受限时提示不可用。
- 限制：生产环境默认隐藏或需要开发者模式。

### 2. AI DevTools 开关

怎么做：
- 输入：enabled。
- 输出：保存成功。
- 写什么数据：写设置项 `switchAiDevTool`。
- 状态怎么变：开关更新；后续新发起的文本模型调用按该开关决定是否接入 AI DevTools middleware。
- 异常怎么处理：保存失败回滚。
- 限制：值统一为 boolean，兼容参考项目 `"1"/"0"`。

### 3. localStorage 列表和搜索

怎么做：
- 输入：搜索关键词。
- 输出：key/value 列表。
- 写什么数据：不写。
- 状态怎么变：过滤列表。
- 异常怎么处理：读取失败提示。
- 限制：敏感 key 默认脱敏显示。

### 4. 新增/编辑 localStorage

怎么做：
- 输入：key、value。
- 输出：保存成功。
- 写什么数据：写 localStorage。
- 状态怎么变：列表刷新。
- 异常怎么处理：key 为空失败；JSON 格式化失败只提示，不强制要求 value 是 JSON。
- 限制：不能编辑受保护 key，除非开发者模式二次确认。

### 5. 删除/清空 localStorage

怎么做：
- 输入：key 或清空确认。
- 输出：删除成功。
- 写什么数据：删除 localStorage 项。
- 状态怎么变：列表刷新，可能触发登录状态变化。
- 异常怎么处理：删除失败提示。
- 限制：清空前必须提示会影响登录、语言、外观、当前项目等状态。

## 5. 数据和状态

```txt
字段：
  switchAiDevTool
  localStorage.*

接口/能力：
  settings.dev.getAiDevTools
  settings.dev.updateAiDevTools
  settings.dev.openDevTools
  renderer localStorage manager

数据读写：
  读写 settings
  读写 renderer localStorage

任务状态：
  不写 tasks 表

轮询/Socket：
  无

模型调用：
  无

删除影响：
  清空 localStorage 会影响登录、语言、外观、当前项目等本地状态
```

受保护 localStorage key：

```txt
认证状态：
  token
  user
  userId

语言状态：
  vtStudio.locale
  vtStudio.localeInitialized

外观状态：
  vtStudio.appearance

通用规则：
  1. `vtStudio.` 前缀的 key 默认视为受保护 key。
  2. 包含 token、secret、key、password、authorization 的 key 默认脱敏显示 value。
  3. 编辑或删除受保护 key 必须二次确认。
  4. 清空全部 localStorage 必须二次确认，并明确会退出登录、重置语言和外观等影响。
```

不写入的状态：

```txt
任务状态：不写 tasks 表。
文件状态：不读写本地文件。
模型状态：除 AI DevTools middleware 是否启用外，不修改模型配置和模型绑定。
```

## 6. VT Studio 怎么落

```txt
能力名：
  settings.dev

调用链：
  renderer 设置页 -> window.vtStudio.settings.dev -> main/ipc -> main/services/dev
  localStorage 管理保留在 renderer，但危险项要二次确认

需要新增：
  设置页开发者配置组件
  dev IPC/service

需要修改：
  生产环境隐藏或保护开发者入口

当前代码现实：
  1. `switchAiDevTool` 已存在于 `app_settings` 默认数据中，但当前没有设置页入口。
  2. renderer 里的本地状态已经明显变多：登录、语言、外观等都写在 localStorage。
  3. 所以 localStorage 管理和“清空全部”现在会直接影响登录状态、语言、外观，以及后续更多本地偏好。
  4. 这意味着开发者配置虽然是工具页，但危险操作必须比参考项目更克制。
```
