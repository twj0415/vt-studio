# OPT-009 视觉手册和导演手册真正参与生成链路

## 通俗总结

这次不是做手册管理页面，而是让手册真正影响生成结果。

参考项目不是只在项目里选一个视觉手册、导演手册摆着看。资产提示词、分镜提示词、视频提示词都会按当前项目读取对应 Skill/手册片段。VT Studio 之前已经能 seed 和编辑手册，但生成链路里还有“选了手册，却没真正用上”的风险。

这次把底层接上：生成资产图、生产分镜图、生产衍生资产图、视频提示词、Production Agent 上下文，都必须读取当前项目的视觉手册和导演手册。读不到就失败，不再静默空跑。

## 要做什么

1. 新增统一手册读取 helper：
   - 输入手册类型、手册 ID、需要的 tab key。
   - 输出手册内容、手册名称、路径、更新时间、内容 hash。
   - 手册不存在、JSON 坏了、关键 tab 为空时直接抛错。
2. 资产提示词生成继续读取视觉手册：
   - 父角色：`prefix + character`
   - 衍生角色：`prefix + characterDerivative`
   - 父场景：`prefix + scene`
   - 衍生场景：`prefix + sceneDerivative`
   - 父道具：`prefix + prop`
   - 衍生道具：`prefix + propDerivative`
3. 资产图片生成也必须读取视觉手册：
   - 之前只用了资产 prompt、图片规则、项目画质。
   - 现在最终图片 prompt 里加入视觉手册内容。
   - `asset_media.metadata` 记录使用的视觉手册摘要。
4. 生产分镜图生成读取两类手册：
   - 视觉手册：`prefix + storyboard`
   - 导演手册：`planning + storyboardTable`
5. 生产衍生资产图生成读取两类手册：
   - 保留父资产图参考。
   - prompt 加入视觉/导演手册规范。
   - `asset_media.metadata` 记录视觉/导演手册摘要。
6. 视频提示词生成读取两类手册：
   - 视觉手册：`prefix + storyboardVideo`
   - 导演手册：`planning + storyboardTable`
7. Production Agent 上下文返回手册内容：
   - Agent 能拿到视觉手册内容。
   - Agent 能拿到导演手册内容。
   - 同时带手册 hash，后续排查知道用的是哪一版。
8. 任务中心记录手册版本摘要：
   - 资产提示词任务。
   - 资产图片任务。
   - 分镜图任务。
   - 生产衍生资产图任务。
   - 视频提示词任务。

## 具体怎么做

1. 新增 `src/main/services/project/manual-prompt.ts`：
   - `readManualPromptBundle()` 统一读取 `visual_manuals` / `director_manuals`。
   - `toManualPromptSnapshot()` 输出轻量版本摘要。
   - `formatManualPromptSection()` 把手册片段拼进模型 prompt。
2. 修改 `src/main/services/assets/service.ts`：
   - `readAssetVisualManual()` 负责按资产类型取视觉手册 key。
   - `buildAssetImagePrompt()` 增加“视觉手册规范”段。
   - `createGenerationMetadata()` 把视觉手册摘要写进 `asset_media.metadata`。
   - 创建资产提示词/图片任务时，把手册摘要写进 `relatedObjects.manuals`。
3. 修改 `src/main/services/production/service.ts`：
   - `ProjectRow` 查询补 `director_manual_id`。
   - `readProductionStoryboardManuals()` 读取分镜图需要的视觉/导演手册。
   - `readProductionVideoManuals()` 读取视频提示词需要的视觉/导演手册。
   - `buildStoryboardImagePrompt()` 把手册内容拼进分镜图 prompt。
   - Production Agent context 增加 `manuals.visual` 和 `manuals.director`。
   - 生产任务 `relatedObjects` 增加手册摘要。
4. 修改 `src/shared/types/production.ts`：
   - 给 Production Agent 上下文补 `ProductionAgentManualContext`。
5. 新增 `scripts/verify-opt-009-manual-generation-chain.mjs`：
   - 检查 helper、资产链路、生产链路、Agent 上下文、任务记录是否接上。
6. 把 verify 脚本接入 `verify:production`。

## 不做什么

1. 不重做手册编辑 UI；手册管理已经在项目管理里。
2. 不新增手册字段名，不改参考项目资源结构。
3. 不把完整生成快照落到所有生产表；完整快照归 `OPT-034`。
4. 不做上游修改后的下游失效规则；这个归 `OPT-054`。
5. 不做孤儿文件清理；这个归 `OPT-036`。

## 完成标准

1. 手册读取只有一套 helper，不再在各服务里各自解析 `tabs_json`。
2. 资产图片最终 prompt 包含视觉手册内容。
3. 分镜图最终 prompt 包含视觉手册和导演手册内容。
4. 视频提示词生成时，模型消息包含视觉手册和导演手册内容。
5. Production Agent 上下文能拿到手册内容。
6. 手册缺失或关键 tab 为空时，生成失败并写失败原因。
7. 任务 `relatedObjects` 或生成媒体 `metadata` 能看到使用的手册版本摘要。
