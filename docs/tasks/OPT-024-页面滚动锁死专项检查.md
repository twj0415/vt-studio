# OPT-024 页面滚动锁死专项检查

## 通俗总结

这次处理“窗口里看得到内容，但滚不动”的问题。

Electron 里 `body` 本来就会被锁住，真正能滚的是工作区和弹窗内部。如果工作区、侧栏或大弹窗没有自己的滚动兜底，用户就会感觉页面卡死。

## 本批范围

1. 修复应用外壳硬性最小宽度导致的小窗口裁切。
2. 保证主内容区 `.content-frame` 是稳定滚动容器。
3. 保证左侧项目菜单过高时自己滚动，不挤掉底部入口。
4. 给 TDesign 弹窗 body 增加全局滚动兜底。
5. 给生产工作台、图片工作流这类大弹窗增加内部高度和滚动规则。
6. 增加专项 verify，防止这些滚动兜底被改回去。

## 不做什么

1. 不重做所有页面 UI。
2. 不修改业务功能和数据流。
3. 不为了滚动问题删除表格内部横向宽度；表格横向滚动仍由表格容器处理。
4. 不改变 TDesign 弹窗组件实现，只做全局样式兜底。

## 具体怎么做

1. `.desktop-frame` 和 `.app-shell` 使用 `100dvh` 兜底，减少窗口高度计算异常。
2. `.app-shell` 不再固定 `min-width: 1180px`，避免小窗口下内容被裁掉且无法滚动。
3. `.content-frame` 增加：
   - `overflow-x: hidden`
   - `overflow-y: auto`
   - `scrollbar-gutter: stable`
   - `scroll-padding`
4. `.project-nav` 增加自己的纵向滚动和 `overscroll-behavior`。
5. `.t-dialog__ctx .t-dialog__body` 增加 `overflow: auto` 和最大高度兜底。
6. `.production-workbench-shell`、`.production-image-flow-shell` 使用 `height: min(..., calc(100dvh - ...))`。
7. 生产工作台侧栏、预览区、详情区、编辑区使用内部滚动。
8. 小窗口单列模式下取消固定高度，让弹窗 body 负责整体滚动。

## 用户能操作什么

1. 设置页长内容可以继续滚到底。
2. 项目页、原文页、剧本 Agent 页内容不会被外壳硬裁切。
3. 打开/关闭弹窗后，弹窗内部内容能滚动。
4. 生产工作台和图片工作流大弹窗在小窗口下仍能看到后续内容。

## 完成标准

1. 主内容区保持唯一稳定滚动容器。
2. 弹窗内容超高时弹窗 body 能滚。
3. 小窗口不再因为外壳 `min-width` 被裁掉后无法滚。
4. 左侧项目菜单过高时不挤掉底部设置/版本入口。
5. 专项 verify 能检查这些关键样式。
