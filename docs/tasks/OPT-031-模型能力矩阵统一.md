# OPT-031 模型能力矩阵统一

状态：已完成

## 0. 快速理解

一句话：把“模型能做什么”收成一张能力矩阵，后面项目配置、提示词绑定、视频生成和工作台都按这张表走。

为什么现在做：图片、视频、TTS、ComfyUI、OpenAI compatible、自定义 adapter 的 mode 和输入要求都不一样。如果不先统一，后面页面能选的、提示词能绑的、真实调用能跑的会互相打架。

做完后有什么用：视频模型的 `text/singleImage/首尾帧/多参考/音频参考` 等 mode 不再靠页面手填字符串，模型服务、提示词映射、项目视频模式、生产工作台和生成校验看到的是同一套 mode key。

这一步不碰什么：不做模型请求取消/超时/重试，不做 adapter 沙盒安全增强，不做 ComfyUI workflow manifest，不保证真实外部 API 已跑通。

## 1. 本次做什么

1. 新增共享模型能力定义：
   - `src/shared/constants/model-capabilities.ts`
   - `src/shared/types/model-capability.ts`
2. 固定视频 mode key：
   - 简单模式：`text`、`singleImage`、`startEndRequired`、`endFrameOptional`、`startFrameOptional`
   - 组合参考：`imageReference:3`、`videoReference:1,imageReference:2`、`audioReference:1,imageReference:1`、`textReference:1,imageReference:1`
3. 扩展 `RegisteredModel`：
   - `imageModes`
   - `videoModes`
   - `durationOptions`
   - `resolutionOptions`
   - `aspectRatioOptions`
   - `audioSupport`
   - `voices`
4. main 侧新增能力矩阵工具：
   - 连接模型转运行 vendor model。
   - vendor model 转普通连接模型。
   - 输出 `capabilityMatrix`。
   - 校验视频模型是否支持当前 mode。
5. 模型服务配置接入能力矩阵：
   - 保存连接时统一 normalize。
   - `getResourceConfig()` 返回 `capabilityMatrix`。
   - 视频测试优先使用 `text` mode，否则用模型第一个 mode。
6. 模型提示词映射接入 mode：
   - image/video 模型按 mode 展开。
   - `model_mode=''` 继续作为默认 fallback。
   - 清除绑定时优先清当前真实 mode。
7. 视频生成接入 mode 校验：
   - mode 不支持直接拒绝。
   - 图片/视频/音频参考数量不足直接拒绝。
   - 模型不支持 audio 时不允许强传 audio。
   - adapter 入参仍保留 string 或 array，不强行破坏旧 adapter。
8. 项目和生产工作台接入 mode 规范：
   - 项目保存兼容旧 JSON 数组 mode。
   - 生产服务把规范 key 还原为 adapter 可理解的数组模式。
   - 视频工作台读取项目默认模型和能力矩阵，不再写假模型 ID。
9. 供应商高级模型编辑改为受控 mode：
   - 视频 mode 从自由输入改为 `VIDEO_MODE_PRESETS` 多选。
   - 保存前用 `parseVideoModeKey()` 转回运行时 mode。

## 2. 关键决定

1. mode 的唯一存储/比较 key 用 `serializeVideoMode()`。
   - `['videoReference:1', 'imageReference:2']` 存成 `videoReference:1,imageReference:2`。
2. adapter 入参不强制改成字符串。
   - 原因：老 adapter 可能按数组判断参考模式，强改会破坏兼容。
3. 模型提示词映射允许两层绑定。
   - `model_mode=''` 是模型默认模板。
   - 具体 `modeKey` 是 mode 专用模板。
4. 生产工作台默认模型用空值。
   - 原因：后端已经支持空模型回退项目 `video_model_id`，前端不能再发 `project-default-video-model` 这种假值。
5. ComfyUI workflow manifest、adapter 安全、取消/超时/重试仍在后续 TODO。
   - 本任务只把能力表达方式收统一，不把所有模型治理一次做完。
