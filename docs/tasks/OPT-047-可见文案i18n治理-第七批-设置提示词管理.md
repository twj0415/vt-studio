# OPT-047 可见文案 i18n 治理 - 第七批：设置提示词管理

状态：已完成

## 0. 快速理解

一句话：这次只处理设置页里的 `PromptConfig.vue`，把内置提示词管理页用户能看到的固定文案全部改成 i18n key。

为什么单独做它：提示词管理是生成链路的核心配置入口。页面里既有默认提示词名称、状态、编辑弹窗，也有结构风险二次确认；如果这里还写死中文，后续英文界面和 AI 续做规范会断层。

这一步不碰什么：不改提示词数据库结构、不改默认提示词内容、不改结构风险规则、不改保存和恢复默认逻辑。

## 1. 扫描结论

`PromptConfig.vue` 的硬编码主要集中在这些地方：

1. 页面标题和说明：提示词管理、只管理内置核心提示词。
2. 操作按钮：刷新、编辑、保存、取消、恢复默认。
3. 状态：已自定义、默认、默认提示词、未记录。
4. 默认提示词名称：事件提取、剧本资产提取、视频提示词生成、音色绑定来自主进程默认中文，页面展示要按 `prompt.type` 映射语言包。
5. 空状态：正在读取提示词、没有读取到内置提示词。
6. 编辑弹窗：编辑提示词、类型、状态、字符数、保存前提示、textarea placeholder。
7. 风险弹窗：提示词结构风险、继续保存可能影响后续生成、仍然保存、返回修改。
8. 恢复默认弹窗：恢复默认提示词、恢复后清空自定义内容并使用内置默认提示词。
9. toast 和校验：提示词内容不能为空、提示词已保存、已恢复默认。

## 2. 要做什么功能：怎么做

| 要做什么 | 怎么做 |
|---|---|
| 组件接入 i18n | `PromptConfig.vue` 引入 `useI18n()`，所有可见静态文案走 `settings.promptConfig.*` |
| 日期格式跟随语言 | `formatUpdatedAt()` 使用当前 `locale.value`，不再固定 `zh-CN` |
| 状态文案改语言包 | `已自定义/默认/默认提示词/未记录` 全部通过语言包显示 |
| 默认提示词名改语言包 | 按 `BuiltinPromptType` 建 `PROMPT_NAME_KEYS`，页面展示和弹窗标题用 `getPromptName()` |
| 风险弹窗改语言包 | 弹窗标题、说明、按钮走语言包；warning 明细继续展示后端返回内容 |
| toast 和校验 | `MessagePlugin` 改用语言包；接口 `response.msg` 继续原样展示 |
| 中英文语言包 | `messages.ts` 新增 `settings.promptConfig.*`，中英文同步补齐 |
| 防回退 | 新增专项 verify，检查 `PromptConfig.vue` 不再出现中文硬编码 |
| 旧校验更新 | `verify-f-002-006` 不再查页面中文，改查 i18n key |
