# OPT-047 可见文案 i18n 治理 - 第九批：设置其他业务配置

状态：已完成

## 0. 快速理解

一句话：这次只处理设置页里的 `BusinessConfig.vue`，把“其他业务配置”页用户能看到的固定文案全部改成 i18n key。

为什么单独做它：这个页面会影响导入章节、请求超时、生产画布滚轮、资产生成并发和剧本长度。文案不多，但保存校验、恢复默认弹窗和按钮都还写死中文，语言切换后会断层。

这一步不碰什么：不改 `settings.business` 数据结构，不改章节正则默认值，不改业务参数范围，不改保存和恢复默认逻辑。

## 1. 扫描结论

`BusinessConfig.vue` 的硬编码主要集中在这些地方：

1. 标题和说明：其他业务配置、业务参数说明。
2. 操作按钮：刷新、恢复默认正则、保存。
3. 表单标签：章节拆分正则、请求超时、生产画布滚轮方式、显示生产交互态、资产生成并发数、剧本单集长度限制。
4. 单选项：缩放、滚动。
5. 保存校验：必须是数字、保存失败。
6. 恢复默认正则弹窗：标题、正文、确认、取消。
7. toast：保存成功、默认正则已恢复。

## 2. 要做什么功能：怎么做

| 要做什么 | 怎么做 |
|---|---|
| 组件接入 i18n | `BusinessConfig.vue` 引入 `useI18n()`，静态文案走 `settings.businessConfig.*` |
| 表单 label 改语言包 | 所有 `t-form-item label` 改成 `:label="t(...)"` |
| 按钮和说明改语言包 | 标题、说明、刷新、恢复默认正则、保存改成 `t(...)` |
| 单选项改语言包 | `zoom/scroll` 仍是业务值，显示文字走 `wheelMode.zoom/scroll` |
| 校验文案改语言包 | `parseInteger()` 改传 label key，错误用 `validation.numberRequired` |
| 弹窗和 toast 改语言包 | `DialogPlugin.confirm`、`MessagePlugin` 固定文案全部走 i18n |
| 中英文语言包 | `messages.ts` 新增 `settings.businessConfig.*` 中英文 |
| 防回退 | 新增专项 verify，检查组件不再出现中文硬编码，并检查语言包和聚合 verify |
| 旧校验更新 | `verify-f-002-012` 不再检查页面中文，改查 i18n key |
