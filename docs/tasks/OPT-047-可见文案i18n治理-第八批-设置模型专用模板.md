# OPT-047 可见文案 i18n 治理 - 第八批：设置模型专用模板

状态：已完成

## 0. 快速理解

一句话：这次只处理设置页里的 `ModelPromptConfig.vue`，把模型专用模板页用户能看到的固定文案全部改成 i18n key。

为什么单独做它：模型专用模板会影响图片/视频模型的生成提示词。页面里有模板库、模型绑定、失效映射、删除确认和绑定弹窗，如果状态和原因继续直接显示中文，会让多语言界面断层。

这一步不碰什么：不改模型模板表、不改绑定规则、不改视频 mode fallback、不改模型服务和提示词解析逻辑。

## 1. 扫描结论

`ModelPromptConfig.vue` 的硬编码主要集中在这些地方：

1. 页面标题和说明：模型专用模板、高级能力说明。
2. 操作按钮：刷新、新增模板、编辑、删除、绑定、清除、保存、保存绑定。
3. 模板类型：图片模板、视频模板。
4. 模板库：模板库、几个模板、几引用、未引用、正在读取模板、空状态。
5. 模型绑定：模型绑定、只显示 image/video 模型、未绑定专用模板、默认模式、当前使用模型默认绑定。
6. 状态直出：`connection.connectionStatusText`、`model.statusText` 不能直接展示主进程中文。
7. 失效映射：失效映射、`mapping.reasonText` 不能直接展示主进程中文。
8. 模板弹窗：新增/编辑模型模板、模板名称、模板类型、模板内容、placeholder。
9. 绑定弹窗：绑定模板、当前模型、选择同类型模板、当前类型没有可绑定模板。
10. toast 和确认弹窗：模板名称和内容不能为空、模板已新增/保存/删除、请选择模板、模型模板已绑定、绑定已清除。

## 2. 要做什么功能：怎么做

| 要做什么 | 怎么做 |
|---|---|
| 组件接入 i18n | `ModelPromptConfig.vue` 引入 `useI18n()`，所有可见静态文案走 `settings.modelPromptConfig.*` |
| 模板类型改语言包 | `TEMPLATE_TYPE_OPTIONS` 改为 `labelKey`，`getTemplateTypeLabel()` 走语言包 |
| 模型类型改语言包 | `getModelTypeLabel()` 按 image/video 映射语言包 |
| 连接状态改语言包 | 按 `connection.connectionStatus` 映射语言包，不展示 `connectionStatusText` |
| 绑定状态改语言包 | 按 `model.status + model.modelType` 映射语言包，不展示 `statusText` |
| 失效原因改语言包 | 按 `mapping.reason` 映射语言包，不展示 `reasonText` |
| 弹窗和 toast | `DialogPlugin.confirm`、`MessagePlugin`、dialog header、confirmBtn、placeholder 全部改语言包 |
| 中英文语言包 | `messages.ts` 新增 `settings.modelPromptConfig.*`，中英文同步补齐 |
| 防回退 | 新增专项 verify，检查 `ModelPromptConfig.vue` 不再出现中文硬编码和后端中文状态直出 |
| 旧校验更新 | `verify-f-002-004` 不再查页面中文，改查 i18n key |
