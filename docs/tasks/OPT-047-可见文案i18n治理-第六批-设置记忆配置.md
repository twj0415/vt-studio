# OPT-047 可见文案 i18n 治理 - 第六批：设置记忆配置

状态：已完成

## 0. 快速理解

一句话：这次只处理设置页里的 `MemoryConfig.vue`，把记忆配置页用户能看到的固定文案全部改成 i18n key。

为什么单独做它：记忆配置控制本地 embedding、摘要、RAG 和清空记忆。这里有高风险“清空全部”操作，如果提示、确认短语和错误文案不跟随语言，会直接影响用户判断。

这一步不碰什么：不改 memories 表结构、不改 embedding 逻辑、不改记忆清理服务、不改默认记忆参数，只处理页面可见文案和前端提示。

## 1. 扫描结论

`MemoryConfig.vue` 的硬编码主要集中在这些地方：

1. 页面标题和说明：记忆配置、本地 embedding、摘要和 RAG 说明。
2. 操作按钮：刷新、恢复默认、保存、校验、清空。
3. 模型状态：ONNX 模型、模型文件可用、模型文件不存在。
4. 表单字段：ONNX 相对路径、消息摘要阈值、短期记忆限制、摘要长度、摘要数量、RAG 数量、深度检索摘要数量。
5. 统计卡片：总记忆、消息、摘要、隔离范围。
6. 清空记忆：指定范围、全部、全部类型、消息、摘要、项目 ID、分集 ID、剧本 Agent、生产 Agent。
7. 高风险确认：恢复默认记忆配置、清空全部记忆、清空指定记忆、确认清空。
8. toast 和校验：模型路径校验失败、保存成功/失败、恢复默认成功、已清理多少条记忆、数字校验失败。

## 2. 要做什么功能：怎么做

| 要做什么 | 怎么做 |
|---|---|
| 组件接入 i18n | `MemoryConfig.vue` 引入 `useI18n()`，所有可见静态文案走 `settings.memoryConfig.*` |
| 模型状态改语言包 | `modelStatusText` 按 `modelAvailable` 推导 i18n 文案 |
| 数字校验改语言包 | 数字字段只传 label key，错误用 `settings.memoryConfig.validation.numberRequired` |
| 清空选项改语言包 | 清空范围、类型、Agent 类型用 option + `labelKey` 渲染 |
| 确认短语多语言 | 页面显示当前语言确认短语；提交给 main 时转换为现有固定确认值，避免破坏已完成后端规则 |
| 弹窗和 toast | `DialogPlugin.confirm`、`MessagePlugin` 改用语言包；接口 `response.msg` 继续原样展示 |
| 中英文语言包 | `messages.ts` 新增 `settings.memoryConfig.*`，中英文同步补齐 |
| 防回退 | 新增专项 verify，检查 `MemoryConfig.vue` 不再出现中文硬编码 |
| 旧校验更新 | `verify-f-002-008` 不再查页面中文，改查 i18n key |
