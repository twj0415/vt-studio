# OPT-047 可见文案 i18n 治理 - 第十一批：设置开发者配置

状态：已完成

## 0. 快速理解

一句话：这次只处理 `DeveloperConfig.vue` 剩下的 `清空 localStorage` 确认短语。

为什么单独做它：开发者配置页主体已经走 i18n，但清空 localStorage 的确认短语还写死中文，英文界面会提示用户输入中文短语，不符合“所有可见文案支持多语言”。

这一步不碰什么：不改 DevTools 开关，不改 localStorage 新增/编辑/删除/清空逻辑，不改受保护 key 规则，不改敏感 key 脱敏。

## 1. 扫描结论

`DeveloperConfig.vue` 当前只剩这些问题：

1. `CLEAR_CONFIRM_PHRASE = '清空 localStorage'` 写死中文。
2. 英文语言包 `clearConfirmPlaceholder` 仍然显示 `Type: 清空 localStorage`。
3. 旧校验 `verify-f-002-014` 仍然要求组件里出现中文短语。

## 2. 要做什么功能：怎么做

| 要做什么 | 怎么做 |
|---|---|
| 确认短语改语言包 | 新增 `settings.devConfig.storage.clearConfirmPhrase` |
| 组件校验改语言包 | `clearAll()` 比对 `getClearConfirmPhrase()` |
| placeholder 改参数化 | `clearConfirmPlaceholder` 改为 `输入：{phrase}` / `Type: {phrase}` |
| 排序跟随语言 | `localeCompare` 使用当前 `locale.value` |
| 防回退 | 新增专项 verify，检查 `DeveloperConfig.vue` 不再出现中文硬编码 |
| 旧校验更新 | `verify-f-002-014` 不再检查中文短语，改查 i18n key |
