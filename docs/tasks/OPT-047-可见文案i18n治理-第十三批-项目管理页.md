# OPT-047 可见文案 i18n 治理 - 第十三批：项目管理页

状态：已完成

## 0. 快速理解

一句话：这次只把项目管理页的可见中文改成 i18n，让项目列表、新建/编辑项目、视觉手册、导演手册、删除确认都能跟随语言切换。

这一步不碰什么：不改项目 CRUD 逻辑，不改数据库字段，不改模型选择规则，不改视觉手册/导演手册的业务结构，不重做 UI 布局。

## 1. 扫描结论

项目管理页当前中文主要集中在 3 个文件：

1. `ProjectHome.vue`
   - 页面标题、说明、刷新/新建/编辑/删除/打开项目按钮。
   - 项目卡片里的图片、视频、视觉手册、导演手册标签。
   - 空状态、视觉手册/导演手册区块说明。
   - 保存、删除、打开失败等 toast/dialog。
   - 删除项目影响说明里的“运行中任务、锁定对象、项目目录”等字段。
2. `ProjectFormDialog.vue`
   - 新建/编辑项目弹窗标题、保存按钮。
   - 项目来源类型、项目名称、题材、简介、图片质量、图片模型、视频模型、视频模式、视频比例、视觉手册、导演手册。
   - placeholder 和表单校验提示。
   - `小说项目`、`剧本项目` 选项。
3. `ManualFormDialog.vue`
   - 新增/编辑视觉手册、导演手册标题。
   - 保存手册按钮、字段 label、封面上传状态。
   - 表单校验提示、Markdown 内容 placeholder。

## 2. 要做什么功能：怎么做

| 要做什么 | 怎么做 |
|---|---|
| 项目管理页接入 i18n | `ProjectHome.vue` 引入 `useI18n`，所有可见文案改成 `t('project.xxx')` |
| 项目表单接入 i18n | `ProjectFormDialog.vue` 引入 `useI18n`，弹窗、表单、placeholder、校验提示全部走 `project.form.*` |
| 手册表单接入 i18n | `ManualFormDialog.vue` 引入 `useI18n`，标题、保存、字段、上传、校验走 `project.manualForm.*` |
| 动态文案保留变量 | 项目名、任务数、锁数量、目录路径、手册 tab 名称继续用变量插入，不写死到业务逻辑 |
| 日期显示跟随语言 | 项目更新时间用当前 locale 传给 `toLocaleString`，不固定 `zh-CN` |
| 防回退 | 新增专项 verify，检查 3 个项目页文件不再有中文硬编码，并加入 `verify:project` 分组 |
