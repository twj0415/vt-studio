# OPT-047 可见文案 i18n 治理 - 第十二批：共享脚手架和设置残留

状态：已完成

## 0. 快速理解

一句话：这次处理设置页清完后剩下的基础残留：模块脚手架状态值、导出占位页状态值、欢迎页语言按钮、外观主题元数据。

这一步不碰什么：不改页面布局，不改功能入口，不改主题 token，不改语言切换逻辑。

## 1. 扫描结论

剩余硬编码主要是：

1. `ModuleScaffold.vue` 用中文状态值做判断。
2. `SettingsHome.vue` 给 `ModuleScaffold` 传中文状态值。
3. `ExportHome.vue` 给 `ModuleScaffold` 传中文状态值。
4. `WelcomeGuide.vue` 语言按钮写死“简体中文”。
5. `settings/appearance/theme.ts` 主题元数据里还有中文名称/说明，虽然页面展示已经走 `messages.ts`。

## 2. 要做什么功能：怎么做

| 要做什么 | 怎么做 |
|---|---|
| 脚手架状态改 key | `ModuleScaffold` 状态改成 `pending/confirm/ready` |
| 设置入口同步 | `SettingsHome` 状态值同步改 key |
| 导出占位页同步 | `ExportHome` 状态值同步改 key |
| 欢迎页语言名 | 语言按钮使用 `language.options.*.label` |
| 外观元数据 | `theme.ts` 元数据改英文/中性值，实际展示仍走 i18n |
| 防回退 | 新增专项 verify，检查这些文件不再有中文残留 |
