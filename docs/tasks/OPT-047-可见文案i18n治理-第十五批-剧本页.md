# OPT-047 可见文案 i18n 治理 - 第十五批：剧本页

状态：已完成

## 0. 快速理解

一句话：剧本 Agent 已经没有中文硬编码；剧本页只收掉批量导入时自动生成的“第 N 集”名称。

这一步不碰什么：不改剧本 CRUD，不改资产提取，不改 AI 生成正则，不改分集解析正则。

## 1. 扫描结论

扫描范围：

1. `src/renderer/src/features/script-agent/ScriptAgentHome.vue`
2. `src/renderer/src/features/script/ScriptHome.vue`

结果：

1. 剧本 Agent 页面未发现中文硬编码。
2. `ScriptHome.vue` 只剩两个中文点：
   - `DEFAULT_SCRIPT_REG`：中文分集解析规则，不是界面文案，本批保留。
   - ``第${number}集``：导入预览里会显示给用户，本批改为 i18n。

## 2. 要做什么功能：怎么做

| 要做什么 | 怎么做 |
|---|---|
| 导入预览剧集名改 i18n | 用 `script.import.episodeName` 和 `script.import.episodeNameWithTitle` 生成草稿名 |

| 防回退 | 新增专项 verify，检查不再出现 ``第${number}集``，并明确 `DEFAULT_SCRIPT_REG` 允许保留 |
