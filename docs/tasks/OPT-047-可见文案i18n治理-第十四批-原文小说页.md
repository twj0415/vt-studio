# OPT-047 可见文案 i18n 治理 - 第十四批：原文/小说页

状态：已完成

## 0. 快速理解

一句话：原文页大部分已经走 i18n，这次只收掉会显示给用户的默认卷名，让导入预览和章节列表不再固定中文“正文卷”。

这一步不碰什么：不改原文导入流程，不改事件分析任务，不改 txt/docx 解析，不改中文章节正则。

## 1. 扫描结论

`NovelHome.vue` 目前页面标题、按钮、弹窗、toast、空状态、表格列、删除确认、事件分析确认都已经走 `source.*`。

剩余需要处理的点：

1. `DEFAULT_VOLUME_NAME = '正文卷'`
   - 这个值会写入导入预览和章节数据，属于用户可见内容。
   - 应改成 `source.import.defaultVolumeName`。
2. `DEFAULT_CHAPTER_REG` 和 `volumeRegex`
   - 里面有中文数字、章回节、卷。
   - 这是中文小说解析规则，不是界面文案。
   - 本批不改，否则会破坏导入能力。

## 2. 要做什么功能：怎么做

| 要做什么 | 怎么做 |
|---|---|
| 默认卷名改 i18n | 删除 `DEFAULT_VOLUME_NAME` 中文常量，新增 `getDefaultVolumeName()` 读取 `t('source.import.defaultVolumeName')` |
| 初始化编辑表单 | `editForm.volumeName` 使用当前语言默认卷名 |
| 章节解析 fallback | `resolveVolumeName()` 和全文 fallback 使用 `getDefaultVolumeName()` |
| 语言包补齐 | `messages.ts` 中 `zh-CN/en` 的 `source.import` 增加 `defaultVolumeName` |
| 防回退 | 新增专项 verify，检查不再出现 `DEFAULT_VOLUME_NAME = '正文卷'`，并说明中文正则是允许的业务解析规则 |

4. 中文章节正则仍保留，导入中文小说不被破坏。
5. 专项 verify、typecheck、content verify、docs verify、build 通过。
