# OPT-047 可见文案 i18n 治理 - 第十批：设置数据库管理

状态：已完成

## 0. 快速理解

一句话：这次只处理设置页里的 `DatabaseManagement.vue`，把数据库管理页用户能看到的固定文案全部改成 i18n key。

为什么单独做它：数据库管理是危险操作页，包含导入备份、清表、清空全部、敏感配置提示和业务锁提示。这里不能只替换按钮文字，还要保证确认短语、动态 toast、危险弹窗和旧校验都对齐。

这一步不碰什么：不改数据库备份目录，不改 main 侧清表/导入/清空全部实现，不改受保护表规则，不改业务锁规则，不改备份文件结构。

## 1. 扫描结论

`DatabaseManagement.vue` 的硬编码主要集中在这些地方：

1. 标题和说明：数据库管理、SQLite 状态说明。
2. 操作按钮：检查任务、刷新、导出备份、导入、清空表、清空全部。
3. 风险提示：高风险操作、完整 SQLite 备份含密钥/token。
4. 信息卡：数据库大小、表数量、迁移记录、运行中任务、锁定对象、数据库路径。
5. 备份恢复：备份恢复、受控目录说明、共几个、选择备份、含敏感配置/不含敏感配置、暂无备份。
6. 表清理：表清理、受保护表说明、选择数据表、影响模块、行数、受保护/可清空。
7. 确认短语：导入数据库、清空全部数据。
8. 动态消息：备份已生成、当前锁定、导入成功、已清空表、已清空并重新初始化。
9. 危险弹窗：导入数据库备份、清空指定表、清空全部数据库业务数据。

## 2. 要做什么功能：怎么做

| 要做什么 | 怎么做 |
|---|---|
| 组件接入 i18n | `DatabaseManagement.vue` 引入 `useI18n()`，所有固定文案走 `settings.databaseManagement.*` |
| 确认短语多语言 | UI 显示当前语言短语；提交 main 前映射回后端现有 `导入数据库`、`清空全部数据` |
| 日期本地化 | `formatDate()` 使用当前 `locale.value`，不再固定 `zh-CN` |
| 锁定对象文案 | `无`、`{label} {count} 个`、中文逗号改语言包组合 |
| 动态 toast | 备份名、自动备份名、删除行数、锁定明细全部用 i18n params |
| 危险弹窗 | header、body、confirmBtn、cancelBtn 全部走 i18n |
| 页面内容 | 标题、说明、警告、信息卡、面板标题、tag、empty、placeholder 全部改语言包 |
| 中英文语言包 | `messages.ts` 新增 `settings.databaseManagement.*` 中英文 |
| 防回退 | 新增专项 verify，检查组件不再出现中文硬编码，并检查语言包和聚合 verify |
| 旧校验更新 | `verify-f-002-010`、`verify-opt-035`、`verify-opt-038` 不再查页面中文，改查 i18n key |
