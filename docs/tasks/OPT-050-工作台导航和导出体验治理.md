# OPT-050 工作台导航和导出体验治理

## 通俗总结

这次先把“导出”这个菜单变成真的能用。

用户进入导出页后，应该能一眼看懂：先选哪个剧本，再检查视频轨道和素材，没问题才能导出剪映草稿；如果导不了，要直接看到缺哪个文件、哪条轨道有问题，不能再是一个空页面。

## 本批范围

第一批只做独立导出页，不重写导出底层，不伪称已经完整兼容剪映原生草稿。

要做什么：

1. `ExportHome.vue` 从 `ModuleScaffold` 占位改成真实导出中心。
2. 页面读取当前项目，不让页面直接访问 SQLite、文件系统或模型 SDK。
3. 通过 `window.vtStudio.script.list` 读取当前项目剧本。
4. 用户选择剧本后，可以构建导出时间线。
5. 用户可以执行导出前素材校验。
6. 校验通过后，才能创建剪映草稿包。
7. 校验失败时，列出失败原因、轨道、路径和服务返回的说明。
8. 导出完成后，显示路径、片段数、复制素材数、时长、任务 ID。
9. 提供打开导出目录、复制路径、去任务中心。
10. 新增可见文案必须走 `src/renderer/src/i18n/messages.ts` 的中英文。

第二批补生产工作台快捷导出：

1. 工作台侧栏显示 `已选择 X/Y 条轨道`。
2. 快捷导出按钮不再只看 `selectedVideoCount`。
3. 只要还有轨道没选成功视频，按钮打开“导出检查”，不直接进入导出。
4. 导出检查列出每条阻断轨道和原因。
5. 阻断项可以定位回对应轨道。
6. 导出确认弹窗里 `copyAssets` 关闭时给风险提示。
7. 导出结果弹窗补复制路径和任务中心入口。
8. 导出失败项有轨道 ID 时可以定位回对应轨道。

第三批补普通用户界面编号治理：

1. 普通用户可见页面不显示 `M-xxx`、`OPT-xxx` 这类开发编号。
2. `ModuleScaffold` 不再接收和展示 `moduleId`。
3. 工作台顶部 eyebrow 不再使用菜单 ID，改成用户能看懂的“全局/项目/应用名”。
4. 生产工作台弹窗和流程节点的标签走 i18n，不写死英文。
5. 专项 verify 扫描 `features` 和 `layouts`，防止开发编号重新出现在普通 UI。

第四批补菜单顺序和导出恢复动作：

1. 项目菜单顺序按真实用户流程排列：流程总览、原文、剧本 Agent、剧本、资产中心、角景音频绑定、生产工作台、导出。
2. 当前布局只保留一组项目模块导航；顶部只放项目上下文、回项目列表、设置，不再形成同级项目菜单重复。
3. 独立导出页支持复制任务 ID。
4. 生产工作台导出结果弹窗支持复制任务 ID。
5. 专项 verify 检查菜单顺序和复制任务 ID 入口。

## 不做什么

1. 不在 renderer 直接查数据库。
2. 不直接读写本地文件。
3. 不新增导出历史表，这个归 `OPT-056`。
4. 不做 WebAV mp4 导出。
5. 不宣称已经输出剪映官方原生草稿结构；当前仍是 VT Studio 可验证草稿包。
6. 不一次性重做生产工作台的大弹窗交互，后续批次再收。

## 具体怎么做

1. 页面加载时读取 `appStore.currentProject`。
2. 没有项目时清空页面数据。
3. 有项目时调用：
   - `window.vtStudio.script.list({ projectId, keyword: null })`
4. 剧本下拉展示剧本名称和剧本 ID。
5. 切换剧本时清空旧的时间线、校验结果和导出结果。
6. 点击“构建时间线”调用：
   - `window.vtStudio.export.buildTimeline({ projectId, scriptId })`
7. 点击“检查素材”调用：
   - `window.vtStudio.export.validateAssets({ projectId, scriptId })`
8. 页面根据校验结果控制导出按钮：
   - 未选剧本：禁用。
   - 未校验：提示先校验。
   - 校验失败：禁用并展示失败项。
   - 校验通过：允许导出。
9. 点击“开始导出”调用：
   - `window.vtStudio.export.createJianyingDraft({ projectId, scriptId, draftName, copyAssets })`
10. 导出成功后调用：
   - `window.vtStudio.export.openDirectory({ path })`
11. 复制路径只复制导出结果路径，不复制失败项内部路径。
12. 去任务中心只跳 `tasks` 路由，不在当前页混入任务列表。

## 用户能操作什么

1. 刷新剧本列表。
2. 跳到生产工作台修视频轨道。
3. 选择要导出的剧本。
4. 填写草稿名称。
5. 保持或关闭复制素材。
6. 构建时间线。
7. 检查素材。
8. 开始导出。
9. 查看失败项。
10. 打开导出目录。
11. 复制导出路径。
12. 去任务中心看任务记录。

## 完成标准

1. `ExportHome.vue` 不再使用 `ModuleScaffold`。
2. 独立导出页至少调用：
   - `window.vtStudio.script.list`
   - `window.vtStudio.export.buildTimeline`
   - `window.vtStudio.export.validateAssets`
   - `window.vtStudio.export.createJianyingDraft`
   - `window.vtStudio.export.openDirectory`
3. 导出按钮必须受素材校验结果控制。
4. 失败项必须展示原因、轨道、说明和路径。
5. 导出结果必须展示路径、片段数、素材数、时长和任务 ID。
6. 页面新增文案必须有中英文。
7. renderer 里不能新增中文硬编码。
8. `verify:export` 必须能检查这一页没有退回占位。
