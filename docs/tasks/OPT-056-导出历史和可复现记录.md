# OPT-056 导出历史和可复现记录

## 通俗总结

这次做的是“导出留档”。

任务中心只告诉用户有一个导出任务成功或失败；导出历史要告诉用户这一次到底导出了什么：哪个剧本、哪些视频轨道、哪些视频候选、素材是否复制、导出到了哪里、失败时缺了什么。

## 本批范围

要做什么：

1. 接入 `export_history` 表迁移。
2. 每次创建剪映草稿时先创建历史记录。
3. 素材校验失败也要更新历史，不能只有任务中心失败。
4. 导出成功后写入输出路径、片段数、复制素材数、总时长。
5. 写入可复现快照：
   - timeline snapshot
   - selected video ids
   - media relativePath
   - copiedPath
   - sizeBytes
   - md5
   - mime
   - exists
   - copyAssets
6. 导出页增加历史列表。
7. 历史列表支持：
   - 按当前项目读取
   - 按当前剧本筛选
   - 查看详情
   - 打开目录
   - 复制路径
   - 复制任务 ID
   - 按历史配置重新校验并准备重导
8. 新增文案走 i18n。
9. 加专项 verify，并挂到 `verify:export`。

## 不做什么

1. 不把导出历史混进任务中心。
2. 不物理删除旧导出文件。
3. 不做项目整体迁移包。
4. 不伪称已经输出剪映官方原生草稿结构。
5. 不在导出历史里写 API Key、请求头或模型密钥。

   - 增加 `ExportHistoryDetail`。

   - 校验失败时写 `failed`、failures、timeline、media snapshot。

   - 历史详情展示素材快照、失败原因和 timeline JSON。
7. `src/renderer/src/i18n/messages.ts`

   - 检查迁移、类型、service、IPC、preload、UI 和文档状态。

## 用户能操作什么

1. 刷新导出历史。
2. 查看某次导出的状态。
3. 查看某次导出的素材快照。
4. 查看某次导出的失败原因。
5. 查看 timeline 快照。
6. 打开导出目录。
7. 复制导出路径。
8. 复制任务 ID。
9. 用历史记录的剧本、草稿名和 copyAssets 配置重新校验，准备再次导出。
10. 跳到任务中心看任务记录。

## 完成标准

1. `export_history` 表随数据库迁移创建。
2. 成功导出有历史记录。
3. 校验失败导出有历史记录。
4. 异常失败导出有历史记录。
5. 历史详情能看到 timeline、selectedVideoIds、素材快照、失败原因。
6. 页面不直接访问 SQLite 或文件系统。
7. 新增可见文案有中英文。
8. `verify:export` 包含 OPT-056 专项检查。
9. `typecheck`、`verify:export`、`verify:docs`、`build` 通过。
