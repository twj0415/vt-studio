# P10 导出批次

状态：已完成（第一版导出主链路）  
覆盖功能：F-010-001 到 F-010-006  
对应功能文档：`docs/features/M-010-导出.md`  
执行口径：用户已确认按批次规划推进；本批次按专业建议直接执行

## 0. 快速理解

```txt
一句话：把 P9 已选视频轨道收口成可校验、可导出的本地导出链路。
为什么现在做：生产工作台已经稳定，导出必须最后读取 selectedVideoId，不能再靠临时界面状态猜。
做完后有什么用：用户能导出分镜图片包，并能从已选视频生成可追踪的草稿目录。
这一步不碰什么：不重新生成素材，不随机选视频，不让 renderer 直接写文件。
```

## 1. 本批次做什么

```txt
主线：
  1. 快速预览分镜图片 zip 导出。
  2. 从 P9 视频工作台已选候选视频构建导出 timeline。
  3. main 侧校验导出素材。
  4. main 侧写本地草稿目录、复制素材并记录任务中心。
  5. 生产工作台新增导出入口和失败详情。

收口决策：
  1. 剪映导出第一版只读取 P9 视频轨道 selectedVideoId。
  2. 没有 selectedVideoId 的轨道必须失败提示，不能随机取候选。
  3. 校验失败不允许强制导出。
  4. 第一版默认复制素材到草稿目录。
  5. 导出写入任务中心。
  6. 导出成功不自动打开目录，只提供打开目录按钮。
  7. 内置 WebAV 编辑器保留入口和边界说明，不在没有 WebAV 依赖时伪造 mp4 导出。
```

## 2. 参考项目怎么做

| 范围 | 参考事实 |
|---|---|
| 快速预览 | Toonflow 前端用 JSZip 按勾选分镜图片打包，拖拽排序只影响本次导出 |
| 内置编辑器 | Toonflow 有前端 WebAV 时间线，但未找到后端保存闭环 |

## 3. 当前实现边界

```txt
第一版剪映草稿 writer：
  先写 VT Studio 可验证草稿包：
    - draft_meta_info.json
    - draft_content.json
    - vt_timeline.json

原因：
  当前项目没有 Jianying Draft Exporter 依赖，也没有已核验的剪映私有 JSON schema。

  接入真实 Jianying Draft Exporter 或核验剪映 draft_content.json schema 后，只替换 writer。
  timeline、素材校验、任务中心、入口、selectedVideoId 规则不变。
```

## 4. 要做什么功能

### 4.1 分镜图片 zip 导出

怎么做：
- 输入：projectId、scriptId、storyboardIds、order。
- 输出：zip 文件路径、成功数量、失败列表。
- 写什么数据：写 userData exports 下的 zip。
- 状态怎么变：renderer loading；不写任务中心。
- 异常怎么处理：未选择、图片为空、文件不存在、格式不支持均返回结构化失败。
- 限制：只导出选中分镜图片，不保存拖拽排序。

### 4.2 导出 timeline 构建

怎么做：
- 输入：projectId、scriptId。
- 输出：ExportTimeline。
- 写什么数据：不写。
- 状态怎么变：无。
- 异常怎么处理：没有轨道、轨道无 selectedVideoId、已选视频不成功、文件路径为空直接失败。
- 限制：只读 P9 视频轨道和 selectedVideoId。

### 4.3 素材校验

怎么做：
- 输入：ExportTimeline。
- 输出：valid、failures。
- 写什么数据：不写。
- 状态怎么变：导出任务 validating。
- 异常怎么处理：路径为空、文件不存在、权限不足、格式不支持都列出 trackId、clipId、sourceType、sourceId、path、reason。
- 限制：校验失败阻止草稿写入。

### 4.4 草稿目录导出

怎么做：
- 输入：projectId、scriptId、draftName、copyAssets。
- 输出：draftPath、timeline、summary、taskId。
- 写什么数据：userData exports 下的草稿目录和 tasks。
- 状态怎么变：running -> succeeded/failed。
- 异常怎么处理：失败写任务中心并返回结构化 msg；已创建目录保留 export_summary 标记失败。
- 限制：不写源码目录，不自动打开目录。

### 4.5 打开导出目录

怎么做：
- 输入：draftPath。
- 输出：opened。
- 写什么数据：不写。
- 状态怎么变：无。
- 异常怎么处理：路径不存在或越界时失败。
- 限制：只允许打开受控 exports 目录内路径。
