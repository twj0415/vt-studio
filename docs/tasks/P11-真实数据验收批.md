# P11 真实数据验收批

状态：已收口  
覆盖范围：P5 到 P10 主业务链路  
对应功能文档：`docs/features/M-004-小说原文.md`、`docs/features/M-005-剧本.md`、`docs/features/M-006-资产中心.md`、`docs/features/M-007-角景音频绑定.md`、`docs/features/M-008-生产工作台.md`、`docs/features/M-010-导出.md`

## 0. 快速理解

```txt
一句话：不用假数据，用真实项目、真实配置、真实媒体把 P5-P10 主链路走一遍。
为什么现在做：P1-P10 第一版已经完成，继续加功能前必须知道真实链路哪里卡住。
做完后有什么用：后续增强不再靠感觉排队，而是按真实验收缺口排优先级。
这一步不碰什么：不自动写演示数据，不直接改用户数据库，不伪装真实模型已跑通。
```

## 1. 验收原则

```txt
1. 禁止写入假数据。
2. 禁止恢复 vt_demo_*、vt-demo-image、vt-demo-video 或 [演示] 数据。
3. 缺少真实模型、真实视频模式、真实手册、真实素材时，记录为验收阻塞，不用假数据补齐。
4. 所有生成类能力必须能在任务中心看到状态和失败原因。
5. renderer 仍然只能通过 preload 调 main service，不能直接访问 SQLite、文件系统或模型 SDK。
6. 验收发现的问题先写入本文件和 TODO，再决定是否开后置增强任务。
```

## 2. 验收范围

### 2.1 P5 原文输入

```txt
1. 导入真实 txt/docx 或粘贴真实文本。
2. 章节拆分、搜索、分页、编辑、删除可用。
3. 事件分析能使用真实文本模型；如果模型未配置，失败原因必须清楚。
4. 事件状态能轮询，任务中心能看到记录。
```

### 2.2 P6 剧本 Agent

```txt
1. 剧本 Agent 能读取真实章节正文和事件摘要。
2. 能保存故事骨架、改编策略和剧本卡片。
3. XML 写入必须落到真实 scripts 表。
4. 子 Agent 调度失败时不能污染已保存数据。
5. 真实模型缺失时记录阻塞，不伪造 Agent 输出。
```

### 2.3 P7 剧本结果

```txt
1. 剧本列表、搜索、新增、编辑、删除、批量导入可用。
2. 剧本 zip 导出文件名、目录和内容可验证。
3. 资产提取能写入真实 assets 和 script_asset_links。
4. 资产提取失败时任务中心有脱敏失败原因。
```

### 2.4 P8 资产和角景音频

```txt
1. 角色、场景、道具、片段、音频资产能真实创建和编辑。
2. 媒体历史能预览真实本地媒体 URL。
3. 提示词生成和图片生成入口能写任务、能失败可追踪。
4. 角景音频绑定只绑定真实 audio 资产。
5. 删除资产的级联和文件清理必须可解释。
```

### 2.5 P9 生产工作台

```txt
1. 能从真实剧本进入生产工作台。
2. Vue Flow 画布、节点、连线、坐标保存可用。
3. 导演计划、分镜表、分镜、衍生资产能保存到真实业务表。
4. 图片工作流能保存、再次打开、回写结果。
5. 视频工作台能创建轨道、维护 mode、参考素材、提示词和候选。
6. selectedVideoId 必须稳定写回轨道。
7. 真实图片/视频执行器未接通时，必须记录为后置缺口，不能用假成功状态替代。
```

### 2.6 P10 导出

```txt
1. 分镜图片 zip 只导出真实选中分镜图。
2. 导出 timeline 只读取 P9 selectedVideoId。
3. 没有 selectedVideoId 时必须阻止导出。
4. 素材不存在、权限不足、格式不支持时必须结构化失败。
5. 草稿目录必须写到受控 exports 目录。
6. 当前只能声明 VT Studio 可验证草稿包，不声明已兼容剪映原生 schema。
```
