# P12 真实生成执行器批

状态：已完成  
覆盖范围：P9 生产分镜图片、生产衍生资产图片、生产视频候选  
前置任务：P8 资产图片生成、P9 生产工作台、P10 导出、P11 真实数据验收批

## 0. 快速理解

```txt
一句话：把 P9 从占位失败任务接到真实 image/video 模型执行器。
为什么现在做：P11 走查确认主链路不能只做到结构通，最终必须能生成真实图片和视频。
做完后有什么用：P9 产出真实项目媒体文件，P10 读取 selectedVideoId 时能拿到真实视频素材。
这一步不碰什么：不新增演示数据，不伪造模型结果，不实现剪映原生 schema，不把 ComfyUI 工作流调度器混入本批。
```

## 1. 问题

```txt
P9 第一版完成了生产工作台结构、任务中心入口、分镜、衍生资产、视频候选和 selectedVideoId。
但真实生成还没有闭环：
1. 分镜图片生成仍走占位失败。
2. 衍生资产图片生成仍走占位失败。
3. 视频候选生成仍走占位失败。
4. P10 虽然能读取 selectedVideoId，但没有真实视频候选时无法完成最终主链路。
```

## 2. 实现范围

```txt
1. P9 分镜图片生成调用 generateImageByModel。
2. P9 衍生资产图片生成调用 generateImageByModel，并写入 asset_media。
3. P9 视频候选生成调用 generateVideoByModel。
4. 生成结果写入 userData/projects 下的受控项目媒体目录。
5. 成功后回写 production_storyboards.relative_path 或 production_videos.relative_path。
6. 失败后回写业务状态、失败原因和任务中心状态。
7. 生成引用素材从已存在的分镜图、资产图、视频、音频或前端传入媒体 URL 转成模型 referenceList。
8. 缺模型、缺 prompt、缺素材、供应商 adapter 未实现时，必须真实失败并记录原因。
```

## 3. 不做范围

```txt
1. 不新增 vt_demo_*、vt-demo-image、vt-demo-video 或 [演示] 数据。
2. 不把内置供应商伪装成已支持 image/video；内置供应商没有 adapter 时继续明确失败。
3. 不实现完整 ComfyUI workflow 节点调度。
4. 不实现 WebAV mp4。
5. 不声明已兼容剪映原生草稿 schema。
6. 不改 P10 selectedVideoId 导出原则。
```

## 4. 技术方案

```txt
1. 在 production service 内补生成媒体落盘 helper：
   - data URL / base64 解码
   - MIME 到扩展名推断
   - 写入 projects/{projectId}/production/*
2. 分镜图片：
   - 使用 project.image_model_id
   - 使用 storyboard.prompt，缺失时失败
   - 关联资产图片作为 image reference
   - 成功回写 production_storyboards.relative_path/image_status
3. 衍生资产图片：
   - 使用 project.image_model_id
   - 使用资产 prompt，缺失时失败
   - 父资产图片作为 image reference
   - 写入 asset_media，更新 assets.media_id/image_status
4. 视频候选：
   - 使用 payload.model 或 project.video_model_id
   - 使用 track.prompt，缺失时失败
   - 使用显式 references；没有显式 references 时自动使用轨道绑定分镜图
   - 成功回写 production_videos.relative_path/status
   - 同步更新 production_video_tracks.status/task_id
5. 任务中心：
   - 每次批量生成创建一个业务任务
   - 部分失败则任务失败，已成功的业务记录保留成功状态
```

## 5. 验收标准

```txt
1. production service 不再保留 P9 生成占位失败常量和 createPlaceholderFailureTask。
2. 分镜图片生成函数直接或间接调用 generateImageByModel。
3. 衍生资产图片生成函数直接或间接调用 generateImageByModel，并写 asset_media。
4. 视频候选生成函数直接或间接调用 generateVideoByModel，并写 production_videos.relative_path。
5. 缺模型或 adapter 未实现时任务失败原因可追踪，不假成功。
6. P9/P10 既有验证、typecheck、build 通过。
```
