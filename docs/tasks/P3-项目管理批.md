## 4. 当前代码现实和不合理点

当前实现和 M-003 目标相比，已经暴露出 6 个明显缺口：

```txt
1. `ProjectHome.vue` 目前仍是 ModuleScaffold 占位，没有项目列表、项目弹窗、手册卡片、打开项目链路。
2. `useAppStore().currentProject` 现在只有极简字段：`id/name/sourceType`，还没有真实项目读取、打开、切换、失效回退语义。
3. main 侧已经有项目运行目录能力：`getRuntimeDirectories().projects`、`resolveProjectRoot()`、`resolveProjectAssetPath()` 等，但项目服务还没有真正接入。
4. 当前没有 `project.*` IPC/service/types，项目 CRUD、模型校验、手册管理都还没落到 `window.vtStudio`。
5. 视觉手册和导演手册目前还没有自己的正式文件管理和引用阻断逻辑。
6. P2 已经把顶部项目菜单依赖 currentProject 定住了，所以 P3 必须补上真实 currentProject 写入链路，否则后续模块只能继续挂空状态。
```

专业结论：

```txt
1. P3 不能只做项目列表界面，必须同时补齐 main/service + preload + store + renderer。
2. 项目记录和项目业务目录必须分开：数据库里存项目元数据，文件系统里存项目业务文件。
3. 删除项目不能只删库；至少要让用户明确选择“只删数据库”还是“删数据库 + 文件”。
```

## 5. 本批次统一实现口径

### 5.1 项目记录和项目目录口径

```txt
数据库负责：
  项目元数据
  模型配置
  手册引用
  当前业务状态

文件系统负责：
  项目业务目录
  原文导入文件
  生成素材
  导出产物
  临时文件

不允许混淆：
  不能把项目创建理解成一定立刻导入文件
  也不能只建数据库记录不管后续项目目录规范
```

### 5.2 项目类型口径

```txt
第一版严格对齐参考项目：
  novel
  script

不扩展第三种项目类型。
顶部项目菜单、打开项目跳转、项目表单字段都按这两个类型定。
```

### 5.3 打开项目口径

```txt
打开项目不是简单 `setCurrentProject + router.push`。
必须先做：
  1. 项目存在校验
  2. image model / video model 可用性校验
  3. 当前项目上下文写入
  4. 按 sourceType 跳 `/novel` 或 `/script`

模型校验失败：
  不直接进入业务页
  提示具体失败原因
  进入编辑项目或重选模型入口
```

### 5.4 手册管理口径

```txt
视觉手册和导演手册继续保留项目级引用语义。
但 VT Studio 正式实现里：
  不照搬旧拼写目录
  不允许危险路径
  删除手册时必须处理项目引用
```

### 5.5 删除项目口径

```txt
删除项目分两个层级：
  1. 删除数据库关联数据
  2. 删除项目业务文件目录

默认建议：
  第一版仍然给用户明确选择，不自动假定一定删文件。

删除当前打开项目：
  成功后必须 clearCurrentProject
  回到项目列表
```

## 6. 本批次要做什么功能

### A. 项目列表和项目卡片

```txt
1. 进入项目页拉项目列表。
2. 展示项目名称、来源类型、简介、手册信息、创建时间。
3. 卡片支持打开、编辑、删除。
```

### B. 新建和编辑项目

```txt
1. 统一使用项目弹窗。
2. 字段包含来源类型、名称、题材/类型、图片模型、图片质量、视频模型、视频模式、视频比例、简介、视觉手册、导演手册。
3. 编辑时必须完整回填，并处理失效模型/失效手册。
```

### C. 打开项目

```txt
1. 先做模型存在性校验。
2. 校验通过后写 currentProject。
3. novel -> `/novel`
4. script -> `/script`
```

### D. 删除项目

```txt
1. 删除前展示影响范围。
2. 阻止误删当前项目。
3. 数据库删除和文件删除分层处理。
```

### E. 项目模型和画质配置

```txt
1. 图片模型只从启用的 image 模型里选。
2. 视频模型只从启用的 video 模型里选。
3. 视频模式来自选中 video model 的能力。
4. 图片质量和视频分辨率语义分开。
```

### F. 视觉手册和导演手册

```txt
1. 项目表单里选择手册。
2. 独立管理弹窗里支持新增、编辑、删除、预览。
3. 删除时处理被项目引用的阻断或清空引用。
```
