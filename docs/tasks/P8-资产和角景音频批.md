# P8 资产和角景音频批

状态：已完成  
覆盖范围：F-006-001 到 F-006-010，F-007-001 到 F-007-005  
对应功能文档：`docs/features/M-006-资产中心.md`、`docs/features/M-007-角景音频绑定.md`

## 1. 合并结论

P8 不再把资产中心和角景音频绑定拆成 15 个小 task 逐个实现。

原因：

```txt
1. 角色、场景、道具、图片生成、提示词生成和角景复用同一张 assets 表。
2. 片段和音频资产都依赖同一套媒体记录、受控文件 URL 和级联删除。
3. 角景页不是独立业务库，它只复用资产中心能力并维护音色绑定。
4. 如果拆开逐个做，会反复修改 migration、assets service、preload、i18n 和两张页面。
```

## 2. 本批次完成什么

```txt
1. 扩展 P7 最小 assets 表，保留剧本提取资产作为资产中心事实来源。
2. 新增 asset_media 和 asset_audio_links，支持媒体历史和角景音色绑定。
3. 资产中心支持 role/scene/tool/clip/audio 五类资产列表、搜索、新增、编辑、删除和批量删除。
4. 片段和音频素材通过 main 受控写入项目目录，并通过本地媒体服务预览。
5. 角色、场景、道具支持单项和批量提示词生成。
6. 角色、场景、道具支持单项和批量图片生成、历史图片选择、取消生成。
7. 角景页查询 role/scene/tool 父资产，并展示历史图片和已绑音色。
8. 角景页复用资产中心的提示词生成、图片生成和图片历史切换。
9. 角景页支持单个音色绑定和批量 AI 音色绑定。
10. 提示词、图片、音频绑定三类状态支持轮询和启动恢复。
11. P7 剧本模块过滤 role/scene/tool，避免 P8 的 clip/audio 进入剧本关联类型。
```

## 3. 明确不做

```txt
1. 不做真正 TTS 音频生成；角景音频绑定只选择已有 audio 父资产。
2. 不做生产工作台中的分镜、视频、流程节点和衍生资产调度。
3. 不做 ComfyUI 工作流编辑；图片生成继续走已存在模型适配层。
4. 不做多个音色绑定；第一版按参考项目保持单音色。
5. 不保留 Toonflow 固定片尾素材。
```

## 4. 关键取舍

### 4.1 扩展 P7 assets 表

P7 已经把剧本提取结果写入 `assets` 和 `script_asset_links`。P8 继续扩展这张表，不新建第二套资产事实来源。

### 4.2 状态统一英文枚举

数据库内部统一使用：

```txt
idle
running
succeeded
failed
cancelled
```

页面显示中文/英文由 i18n 映射，不保存参考源码里的中文状态。

### 4.3 角景页不做 TTS

批量绑定音频只从已有 audio 父资产中选一个音色，模型输出是单个 `audioId`，不是数组，也不生成新音频文件。

### 4.4 资产删除做完整级联

删除资产会清理：

```txt
子资产
asset_media
asset_audio_links
script_asset_links
受控项目文件
```
