# P9 生产工作台批次

状态：已完成  
覆盖范围：F-008-001 到 F-008-015  
对应功能文档：`docs/features/M-008-生产工作台.md`
源码对齐分析：`docs/tasks/P9-生产工作台源码对齐分析.md`

## 1. 合并结论

P9 不再拆成 15 个小 task 逐个实现，改为一次收口生产工作台主链路。

原因：

```txt
1. 选择剧本、flowData、流程画布、分镜、衍生资产、视频轨道共享同一个生产上下文。
2. 分镜图片、视频提示词、视频候选都依赖同一套 storyboards/video_tracks/videos 状态。
3. Production Agent 工具最终也要写这些业务表，不能各做各的临时状态。
4. 画布如果先用临时列表实现，后续 Vue Flow 会大面积返工。
```

## 2. 本批次做什么

```txt
1. 新增生产工作台数据表，区分画布快照和业务事实表。
2. 使用 Vue Flow 实现真实生产画布，支持节点、连线、拖拽、缩放、小地图、控制器、自动布局和坐标保存。
3. 顶部支持剧本选择、刷新流程数据、保存流程数据、自动布局。
4. 节点覆盖剧本、导演计划、资产、分镜表、分镜、视频工作台。
5. 支持导演计划、分镜表保存。
6. 支持衍生资产新增、删除、图片生成和状态轮询。
7. 支持分镜新增、编辑、删除、批量删除、关联资产、图片生成和状态轮询。
8. 支持视频工作台轨道新增、删除、提示词生成、视频候选生成、选择候选和状态轮询。
9. 生成类任务进入任务中心，失败原因可追踪。
10. 为 Production Agent 预留稳定服务接口，但第一版不把完整 Agent 调度混入画布实现。
```

## 3. 明确不做

```txt
1. 不做剪映草稿导出；归 P10 导出批次。
2. 不做完整内置视频编辑器时间线闭环；P9 只做视频工作台轨道和候选。
3. 不做 ComfyUI 工作流编辑；图片工作流只保留 flowId/flowData 承载点。
4. 不把 Agent 输出直接写 renderer 状态；后续 Agent 工具必须走 main service。
5. 不保留 Toonflow 固定片尾素材。
```

## 4. 关键取舍

### 4.1 画布一步到位

画布直接使用 Vue Flow，不手写 SVG 画布。P9 必须完成节点、边、拖拽、缩放、小地图、控制器、自动布局和坐标保存。

### 4.2 业务事实不藏在 flowData

`production_workspaces` 只保存画布快照、导演计划、分镜表和节点坐标。资产、分镜、轨道、视频候选以业务表为准。

### 4.3 状态统一英文枚举

内部统一使用：

```txt
idle
running
succeeded
failed
cancelled
```

页面显示由 i18n 映射。

### 4.4 视频编辑器后置

视频工作台第一版只保证轨道、提示词、候选视频和选择关系稳定，为 P10 导出提供依据。

### 4.5 P9 临时演示数据规则（P10 后已清理）

这是 P9 开发期间为避免空环境下项目创建页缺少必填项而保留的历史规则。P10 后已清理，默认初始化不再自动注入演示模型、演示视频模式或演示手册。

```txt
1. 历史演示数据只能用于补齐项目创建必填项：图片模型、视频模型、视频模式、视觉手册、导演手册。
2. 历史演示数据必须使用 vt_demo_* 固定标识或 [演示] 名称前缀。
3. 默认初始化必须清理明确标识的历史演示数据，不再新增 vt_demo_* 或 [演示] 数据。
4. 清理范围只允许命中 vt_demo_* 标识、vt-demo-image、vt-demo-video 和 [演示] 名称前缀。
5. 清理测试数据时禁止删除用户手动创建的项目、剧本、资产、真实模型连接和真实手册。
6. 如果空环境缺少图片模型、视频模型、视频模式或手册，必须引导用户配置真实数据，不能再用假数据补齐。
```

## 5. 验收

```txt
1. 生产页不再是占位页。
2. 画布使用 Vue Flow 渲染，能拖拽、缩放、自动布局和保存坐标。
3. 有剧本时默认选择第一个剧本。
4. 无剧本时显示明确空状态。
5. 刷新流程会从数据库重建资产、分镜、轨道和候选。
6. 保存流程只保存快照和坐标，不覆盖业务事实。
7. 分镜可以新增、编辑、删除、批量删除、关联资产。
8. 分镜图片生成进入任务中心，成功/失败能轮询。
9. 衍生资产图片生成进入任务中心，成功/失败能轮询。
10. 视频提示词生成和视频候选生成进入任务中心，成功/失败能轮询。
11. 选择候选视频后，轨道有稳定 selectedVideoId，供 P10 导出读取。
12. renderer 不直接访问 SQLite、文件系统或模型 SDK。
13. verify-p9-production、typecheck、build 通过。
```
