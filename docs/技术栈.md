# 技术栈

## 应用

- Electron + electron-vite 桌面应用。
- Vue 3、TypeScript、TDesign Vue Next、Pinia、Vue Router、vue-i18n、Tailwind CSS、SCSS、Vue Flow。
- 主进程使用 TypeScript、better-sqlite3、本地文件与媒体 HTTP 服务、任务和导出服务。
- AI 层使用 Vercel AI SDK、供应商 adapter、文本/图片/视频/TTS 能力配置和 ComfyUI workflow。

## 目录

```text
src/main      主进程、数据库、模型、任务、导出和本地文件
src/preload   安全暴露 API
src/renderer  Vue 前端
src/shared    跨进程类型、常量和状态码
resources     默认资源和供应商数据
scripts       验证脚本
docs          当前有效文档
```

别名：`@shared` 指向 `src/shared`，`@renderer` 指向 `src/renderer/src`。

## 命令

项目锁定 `pnpm@10.24.0`，必须使用：

```text
D:\software\nodejs\pnpm.cmd install
D:\software\nodejs\pnpm.cmd run dev
D:\software\nodejs\pnpm.cmd run typecheck
D:\software\nodejs\pnpm.cmd run build
D:\software\nodejs\pnpm.cmd run verify
```

禁止直接运行 `pnpm`、`npx pnpm` 或使用 Codex bundled pnpm/node。

按改动范围补充运行：

```text
D:\software\nodejs\pnpm.cmd run verify:production
D:\software\nodejs\pnpm.cmd run verify:export
D:\software\nodejs\pnpm.cmd run verify:docs
```
