# 模型能力与参数联动

核验日期：2026-07-15。

## 架构结论

```text
能力目录：模型能做什么
adapter：参数怎么传、结果怎么解析
SQLite：用户配置了什么
能力解析器：当前连接下哪些操作真正可用
页面：只展示能力解析结果
```

| 数据 | 唯一数据源 | 编辑规则 |
| --- | --- | --- |
| 官方模型清单和能力事实 | `src/main/services/model/capability-catalog.ts` | 随应用版本维护，只读，不允许用户修改 |
| 官方和自定义 adapter | `resources/default-data/vendors/*.ts` 及受管供应商代码 | 代码维护，不通过能力表单修改协议 |
| 连接、Key、Base URL、启用模型、默认绑定 | SQLite `app_settings` | 用户可配置 |
| 自定义模型及能力声明 | SQLite 连接配置中的模型数据 | 只能配置所属 adapter 已实现的标准能力 |
| 供应商运行投影 | SQLite `model_vendors` | 由连接同步生成，不是官方能力数据源 |
| 最终能力矩阵 | 主进程运行时计算 | 不持久化，不允许页面自行拼装 |
| 生成任务参数和能力快照 | SQLite 任务及生产数据 | 创建任务后固定，用于追溯 |

官方能力不复制到数据库，避免应用升级后继续读取旧能力。自定义模型没有官方目录记录时，可以保存保守的能力声明，但不能编辑请求字段、鉴权、轮询或返回解析；这些协议逻辑始终由 adapter 决定。

## 最终规则

```text
设置默认模型 -> 创建项目时预选
项目默认模型 -> 创建任务时预选
任务实际参数 -> 保存请求和结果快照
```

上一级只提供初始值。修改设置不影响已有项目，修改项目不影响已创建任务。

| 位置 | 配置内容 |
| --- | --- |
| 设置 | 供应商、连接、Key、启用模型、模型测试、默认文本/图片/视频/TTS 模型 |
| 新建/编辑项目 | 视频比例、图片质量、默认图片模型、默认视频模型 |
| 图片生成 | 实际模型、规格、比例、参考图和模型专属参数 |
| 视频生成 | 实际模型、操作、时长、分辨率、参考素材、音频和模型专属参数 |
| Agent 设置 | 角色提取、场景提取、道具提取、分镜拆分等文本工作流绑定 |

设置页按供应商和连接管理；项目页和工作台按文本、图片、视频、TTS 类型选择。项目不保存视频模式，模式由单次任务根据素材决定。

## 可用条件

有效能力按以下交集计算：

```text
官方能力目录或自定义模型能力声明
∩ adapter 已实现能力
∩ 当前连接已启用模型
∩ 当前操作测试通过
```

运行主键为 `connectionId + modelName + operationId`。同名模型来自不同连接时分别计算，不能按模型名称继承能力。

能力必须表达：

- 操作：文生图、图生图、文生视频、单图视频、首尾帧、多参考等。
- 输入槽位：类型、角色、格式、大小、最少和最多数量。
- 合法组合：时长、分辨率、比例或图片规格。
- 音频：不支持、可选、必须或原生音画。
- 状态：来源、adapter 实现状态和测试状态。

前端负责筛选选项，主进程在调用 adapter 前再次校验。

禁止兼容旧能力格式或使用通用模式、时长、分辨率兜底。能力字段不完整时，模型直接不可用；能力协议变化后必须重启主进程。

`SERVICE_META` 只允许保存连接协议、默认地址和初始模型标识，不得重复保存时长、分辨率、参考数量等能力事实。页面组件不得内置模型选项，也不得从模型名称猜测能力。

## 能力维护

### 官方模型

- 以具体模型为单位登记，不按供应商共享能力。
- 每个操作分别登记输入槽位、合法参数组合、音频能力、来源、核验时间和 adapter 状态。
- 设置页只读展示能力来源和可用状态，不提供编辑入口。
- 未进入能力目录、能力字段不完整或 adapter 未实现的操作不进入选择器。

### 自定义模型

- 必须先选择已实现的 adapter，再登记模型 ID 和模型类型。
- 能力编辑器只展示该 adapter 支持的标准操作和参数，不允许自由填写协议字段。
- 视频时长、分辨率和比例按合法组合逐组保存，不能拆成几个独立数组后任意组合。
- 自定义能力只对 `connectionId + modelName` 生效，不能继承同名官方模型或其他连接的能力。
- 保存前做结构校验；操作测试通过后才进入项目和工作台选择器。

### adapter

- 负责鉴权、请求参数映射、异步任务轮询、错误解析和统一结果输出。
- 不负责决定页面显示哪些选项，也不在内部补默认时长、分辨率、模式或参考素材。
- 能力编辑不能让 adapter 获得尚未实现的操作。

## 页面联动

### 设置

- 配置连接并按文本、图片、视频、TTS 绑定全局默认模型。
- 连接测试只证明鉴权；模型必须按具体操作测试。
- 官方模型能力只读；自定义模型可以配置保守能力，但不能绕过 adapter。

### 项目

- 默认图片和视频模型读取设置绑定，不再取列表第一项。
- 图片质量随图片模型过滤。
- 视频比例属于项目。
- 视频模式、时长、分辨率、参考素材和音频不放项目表单。
- 项目引用失效或弃用模型时阻止生成并要求用户重新选择。

### 工作台

- 默认选中项目模型，允许单次任务覆盖。
- 有正式分镜图时默认选择图生视频并自动带入。
- 切换模型或操作后，立即纠正无效时长、分辨率和参考素材。
- 失败结果不进入候选；成功结果保存实际请求快照。

## 代码边界

| 文件 | 职责 |
| --- | --- |
| `src/shared/types/model-capability.ts` | 通用能力类型 |
| `src/shared/constants/model-capabilities.ts` | 稳定枚举和少量默认常量 |
| `src/main/services/model/capability-catalog.ts` | 官方模型与逐操作能力事实 |
| `src/main/services/model/capability-matrix.ts` | 合并能力目录或自定义声明、adapter 状态、连接和测试状态 |
| `src/main/services/model/capability-validation.ts` | 统一参数和参考素材校验 |
| `src/main/services/settings/model-config.ts` | 连接、自定义模型、默认绑定和测试状态持久化 |
| `resources/default-data/vendors/*.ts` | 供应商预设、连接字段和初始模型清单 |

供应商 adapter 只负责请求映射。能力事实统一管理，但类型、合并、校验和 adapter 不塞进同一个文件。

`capability-matrix.ts` 不得把旧 `mode`、`durationOptions`、`resolutionOptions` 转成可用能力，不得创建 `legacy-config` 来源，也不得在能力缺失时回退到模型配置。`model_vendors` 只是 adapter 运行投影，不能反向覆盖连接和能力目录。

`projects.video_mode` 可以暂时保留为待迁移列，但新代码不读取它，也不得作为运行兜底。

## 验收

1. 设置默认模型能正确预选到新项目。
2. 修改设置不影响已有项目，修改项目不影响已有任务。
3. 图片质量随图片模型变化。
4. 视频模式、时长和分辨率只显示合法组合。
5. 正式分镜图能实际提交给图生视频模型。
6. 同名模型跨连接不会串能力。
7. 失败任务保留真实错误且不进入候选。
