# 项目功能清单

本文只记录当前已有入口或代码能力，不代表全部已完成生产验收。未完成事项见 `后续目标与待办.md`。

项目主流程：

```text
内容 -> 资源 -> 分镜 -> 分镜画面 -> 视频 -> 导出
```

## 功能

| 模块 | 当前已有能力 |
| --- | --- |
| 应用壳 | 本地登录、路由守卫、全局与项目导航、最近项目恢复、版本和反馈入口 |
| 设置 | 外观、语言、模型连接、供应商 adapter、模型能力绑定与测试、Agent、Prompt、Skill、记忆、数据库、文件和诊断 |
| 项目 | 新建、编辑、删除、打开、模型和画质配置、视频比例、视觉/导演手册、项目包导入导出 |
| 内容 | txt/docx/粘贴导入、章节拆分、搜索、分页、编辑、删除、事件分析和下游复查标记 |
| 内容 Agent | 对话、停止与重试、记忆、思考等级、上下文工具、故事骨架、改编策略、剧本卡片和子 Agent |
| 剧本 | 新增、批量处理、编辑、删除、搜索、导入导出、AI 正则和资源提取 |
| 资源 | 角色、场景、道具、片段、音频、草稿审核、Prompt、图片生成、批量任务、媒体历史和手册快照 |
| 角景音频 | 角色/场景/音频列表、绑定、批量绑定、生成状态和资源生成复用 |
| 生产工作台 | 流程总览、步进页面、Vue Flow 画布、资源审核、分镜、分镜图、图片工作流、视频片段和 Production Agent 工具 |
| 图片/视频生成 | 资产图、分镜图、视频候选、批量生成、状态轮询、预览、下载、远程或 Base64 结果落盘和 requestId 追踪 |
| 任务中心 | 项目/分类/状态筛选、分页、失败原因、模型/Agent/导出任务和异常中断恢复 |
| 导出 | 分镜图片 zip、正式视频时间线、导出前校验、草稿包、历史、详情、快照和任务跳转 |
| 本地能力 | SQLite、受控文件读写、本地媒体服务、Range 读取、默认资源恢复、请求/Socket 诊断、日志和脱敏 |

## 当前边界

- 模型已登记不等于 adapter 已实现或生产测试通过。
- 资源、分镜画面和视频候选仍有部分版本与审核能力待完善。
- 时间线剪辑能力尚未完成。
- 具体缺口和验收口径只在 `后续目标与待办.md` 维护。
