# 改编策略格式

## 必填模块

1. 核心改编原则：说明改编目标、叙事重心、平台风格。
2. 删除决策：列出删除或合并的情节，并说明原因。
3. 世界观呈现策略：说明设定如何通过画面、对白、冲突呈现。
4. 人物关系策略：说明主角、反派、关键配角的推进方式。
5. 节奏策略：说明免费集、付费点、高潮和结尾安排。

## 约束

- 所有策略必须能落到剧本和分镜。
- 不写空泛形容词，必须说明执行办法。
- 删除必须说明对主线是否有影响。
