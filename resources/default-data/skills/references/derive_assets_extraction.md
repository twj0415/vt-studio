# 衍生资产提取

## 要做什么

根据剧本和已有资产，分析角色、场景、道具在不同剧情段落中的状态变化。

## 输出字段

| 字段 | 说明 |
| --- | --- |
| assetId | 基础资产 ID |
| assetName | 基础资产名称 |
| deriveName | 衍生状态名称 |
| sceneContext | 出现场景和剧情上下文 |
| visualChange | 视觉变化点 |
| prompt | 英文绘图提示词 |

## 约束

1. 只能基于已有基础资产生成衍生状态。
2. 不新增基础角色、基础场景或基础道具。
3. 衍生变化必须服务剧情或分镜。
