# 事件提取

## 要做什么

从一章小说原文里提取一条结构化事件记录，用于后续分集、改编和剧本生成。

## 输出格式

只输出一行 Markdown 表格，不输出解释：

```markdown
| 第X章 {章节标题} | {涉及角色} | {核心事件} | {主线关系} | {信息密度} | {预估集长} | {情绪强度} |
```

## 字段规则

- 章节：使用原文章节序号和标题。
- 涉及角色：只写有实际戏份的角色，多个用顿号分隔。
- 核心事件：30-60 字，必须包含动作和结果。
- 主线关系：只能是 `强（理由）`、`中（理由）`、`弱（理由）`。
- 信息密度：只能是 `高`、`中`、`低`。
- 预估集长：只能写 `X秒`，不能写分钟。
- 情绪强度：用文字标签，多个用 `+` 连接。

## 约束

1. 忠于原文，不推测、不脑补。
2. 多条事件线并行时，优先选择对主角影响最大的事件。
3. 对话密集章节关注对话造成的结果，不复述对话。
