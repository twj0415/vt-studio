# 小说角色提取

## 要做什么

从原文中找出重要角色，并提取可画出来的视觉信息。

## 输出字段

| 字段 | 说明 |
| --- | --- |
| name | 角色名称，使用原文主要称呼 |
| gender | 性别，无法判断则留空 |
| age | 年龄或年龄段，无法判断则留空 |
| appearance | 五官、发型、体态等外观 |
| costume | 服饰、配饰、材质和颜色 |
| temperament | 气质、表情、姿态 |
| variants | 剧情中出现的明显状态变化 |
| prompt | 英文绘图提示词 |

## 约束

1. 只提取对剧情或视觉制作有意义的角色。
2. 不把同一角色的别称当成新角色。
3. prompt 只描述视觉特征，不写剧情总结。
