# 小说道具提取

## 要做什么

提取原文中有独立视觉意义或剧情功能的道具。

## 输出字段

| 字段 | 说明 |
| --- | --- |
| name | 道具名称 |
| type | 武器、法器、药物、日用品等 |
| appearance | 形状、颜色、材质、尺寸 |
| function | 剧情功能或使用方式 |
| stateVariants | 不同状态或特效变化 |
| prompt | 英文绘图提示词 |

## 约束

1. 普通背景物件不单独提取，除非它推动剧情。
2. 不补写原文没有的材质、颜色或能力。
3. 同一物品不同叫法要合并。
