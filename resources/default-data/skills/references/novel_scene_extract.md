# 小说场景提取

## 要做什么

提取原文中的重要场景，用于场景概念图和后续分镜制作。

## 输出字段

| 字段 | 说明 |
| --- | --- |
| name | 场景名称 |
| category | 室内、室外、城市、自然、幻想空间等 |
| spatialLayout | 空间结构和视线层次 |
| lighting | 光照方向、时间、天气、氛围 |
| keyProps | 关键陈设或标志物 |
| colorPalette | 色调基调 |
| prompt | 英文绘图提示词 |

## 约束

1. 同一地点的白天/夜晚可作为状态描述，不默认拆成两个场景。
2. 不加入原文未出现的建筑、陈设或时代元素。
3. prompt 必须可直接用于场景图生成。
