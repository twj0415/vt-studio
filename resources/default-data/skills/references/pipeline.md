# 剧本流水线

## 执行顺序

1. 事件提取：从原文中提取章节事件。
2. 故事大纲：根据事件设计分集、三幕结构和付费卡点。
3. 改编方案：确定删减、合并、世界观呈现和人物弧线。
4. 成稿编写：输出可制作的竖屏短剧成稿。

## 协作规则

- 决策层负责判断阶段和派发任务。
- 执行层负责读取数据并写入阶段产物。
- 监督层负责审核格式、逻辑和制作可行性。

## 质量门

每个阶段完成后必须确认：格式正确、字段完整、未脱离原文、能被下一阶段读取。
