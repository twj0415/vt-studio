# 剧本格式

## 基本结构

1. 文件头：剧集编号、标题、预计时长、主要角色。
2. 节拍结构：开场、冲突、反转、卡点。
3. 分镜脚本：画面、人物动作、对白、音效、转场。

## 分镜字段

| 字段 | 说明 |
| --- | --- |
| 镜号 | 当前分镜编号 |
| 时长 | 秒 |
| 景别 | 远景、全景、中景、近景、特写 |
| 画面 | 可直接拍摄或生成的画面描述 |
| 台词 | 角色对白、旁白、内心独白 |
| 音效 | 环境声、动作声、音乐提示 |

## 约束

- 画面必须具体可执行。
- 台词不能脱离角色性格。
- 单集节奏必须服务付费点或剧情推进。
